# 雀魂牌谱统计指标说明

本项目的统计规则对齐 [amae-koromo-scripts](https://github.com/SAPikachu/amae-koromo-scripts) 的判定逻辑，基于雀魂协议中的 Record 事件逐局、逐人汇总。

---

## 一、数据来源与统计范围

- **输入**：`data/raw/` 下每局牌谱 JSON（含 `head` 与 `actions`）。
- **单位**：每局 4 名玩家各产生一行「局-人」记录；多局汇总时按 `account_id` 聚合。
- **事件**：仅统计协议中的 `.lq.Record*` 事件（RecordNewRound、RecordDiscardTile、RecordHule、RecordNoTile 等），不依赖外部数据库。

---

## 二、单局输出字段（每局每人一行）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| **game_uuid** | string | 牌谱唯一标识（下划线前的 UUID）。 |
| **account_id** | string | 玩家账号 ID，多局聚合时的唯一标识。 |
| **nickname** | string | 该局中的昵称（可能每局不同）。 |
| **seat** | int | 座次，0=东家、1=南家、2=西家、3=北家。 |
| **initial_point** | int | 该局起始点数（通常东一局为 25000）。 |
| **final_point** | int | 该局结束时的总点（result.players 中的 total_point）。 |
| **rank** | int | 顺位：1=一位，2=二位，3=三位，4=四位；按终盘分从高到低排序得到，与 amae-koromo 一致。 |
| **wins** | int | 和了次数（自摸或荣和均计 1 次）。 |
| **deal_in** | int | 放铳次数（仅荣和时，点炮者计 1 次；自摸不计放铳）。 |
| **riichi** | int | 立直宣言次数（RecordDiscardTile 中 is_liqi=true 的次数）。 |
| **melds** | int | 副露次数（吃/碰/明杠/加杠/暗杠 各计 1 次，RecordChiPengGang + RecordAnGangAddGang）。 |
| **no_ten_tenpai** | int | 流局听牌次数（仅 RecordNoTile 流局时，该玩家 tingpai=true 则计 1 次）。 |
| **games** | int | 局数，单局为 1。 |

---

## 三、聚合报告中的指标（summary_report.xlsx）

对多局按 **account_id** 聚合后，除上述计数的加总外，还包含以下**比率**（均为「总和/总局数」）：

| 字段名 | 含义 | 计算方式 |
|--------|------|----------|
| **games** | 总局数 | 该玩家参与的对局数。 |
| **wins** | 和了总数 | 所有局 wins 之和。 |
| **win_rate** | 和了率 | wins / games。 |
| **deal_in** | 放铳总数 | 所有局 deal_in 之和。 |
| **deal_in_rate** | 放铳率 | deal_in / games。 |
| **riichi** | 立直总次数 | 所有局 riichi 之和。 |
| **riichi_rate** | 立直率 | riichi / games。 |
| **melds** | 副露总次数 | 所有局 melds 之和。 |
| **meld_rate** | 副露率 | melds / games。 |
| **rank_avg** | 平均顺位 | 各局 rank 的算术平均。 |
| **no_ten_tenpai** | 流局听牌总次数 | 仅流局且听牌时累计。 |

**默听率**、**平均向听数**等可在后续版本中按 amae-koromo 的扩展统计再增加。

---

## 四、与 amae-koromo 的对应关系

- **顺位**：按 `result.players` 的 `total_point` 从高到低排序，1～4 位，与 amae-koromo 的顺位定义一致。
- **和了 / 放铳**：依据 `RecordHule`；放铳者取「上一手打牌者」（last_discard_seat），自摸由 `hules[0].zimo` 判定。
- **立直**：`RecordDiscardTile.is_liqi == true` 时计 1 次。
- **副露**：`RecordChiPengGang`（吃/碰/明杠）与 `RecordAnGangAddGang`（暗杠/加杠）各计 1 次。
- **流局听牌**：仅统计 `RecordNoTile` 中的 `players[i].tingpai == true`，按座次 i 对应 seat；`RecordLiuJu` 等特殊流局当前不统计听牌。

---

## 五、友人场与规则兼容

- 初始分、是否赤宝等可从 `head.config` 读取，当前统计不区分规则；若需按规则分模式统计，可后续按 `config.meta.room_id` / `mode_id` 等拆分。
- 三人局时 seat 仍为 0～2，逻辑与四人局一致。

---

## 六、文件与命令

- **单局明细**：`python -m scripts.analyzer -i data/raw -o stats.csv` 生成每局每行 CSV。
- **聚合报告**：`python -m scripts.archiver` 生成 `output/summary_report.xlsx`，内含按 account_id 聚合的上述指标与比率。
